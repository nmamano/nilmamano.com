One of my favorite features I shipped!

1. Ask an agent for a personal-software app.
2. The agent registers it with the meta-harness (which handles ports and gives it a subdomain).
3. It appears in the Apps page of the meta-harness. (You can see apps registered by different agents on behalf of different users.)
4. Open the app from any device, like my phone.
5. The button in the app messages the agent back.
6. The agent acts on the message, forming a closed loop.

This follows up from a concept I shared recently: meta-harnesses as personal-software suites.
