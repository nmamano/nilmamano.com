This is part of a pattern I'm noticing: giving agents an escape hatch.

Instead of, "Do task A," something more like, "Try to do task A, but if there are any issues, do this instead."

This gives agents a way to satisfy our instructions without hacks - or in this case, without working around bad tooling silently.
