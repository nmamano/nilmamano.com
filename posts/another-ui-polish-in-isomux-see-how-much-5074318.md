Another UI polish in Isomux: see how much context you have left.

When context is 50% and 75% full, the agent gets a notification to start nudging it towards wrapping up.

Combine this with the /handoff skill, which asks the agent to suggest a handoff prompt and, with your approval, clears its own session and starts from that prompt.
